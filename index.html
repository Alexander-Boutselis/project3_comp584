My Work

For Project 1, I built a single-column, 600px-wide email campaign themed around the Flying Spaghetti Monster. Inside the main table, I implemented a two-column section (hero image + welcome text) and a separate three-column section using nested tables.

I added responsiveness with a mobile media query that turns each multi-column cell into a block-level element, so the columns stack vertically on screens under 600px. The button includes a hover animation using CSS keyframes, and I experimented with additional animations such as a spin effect that can be tiggered when the mouse hovers near it.

I had no placeholder images and lorem ipsum text so I made sure eveything worked and was dynamic, including a hero image, text info, button, and footer. The footer includes an unsubscribe link that points to my GitHub repo, which also contains an asset folder with my report documenting my testing notes across different email clients.

My Work

For Project 2 I continued building off of the mobile-first dog adoption layout using Flexbox. Each row is a flex container with column classes that resize at tablet and desktop breakpoints. Rows 1,2, and 3 were provided witht he instructions

Row 3 implements the required 1-column / 3-column layout, row 4 is a full-width single item, and row 5 uses a 1-2-1 layout with the Flexbox order property to change item order on tablet vs. desktop.
